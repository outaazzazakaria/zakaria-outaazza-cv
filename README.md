# CV en ligne - Zakaria Outaazza

CV interactif et responsive de **Zakaria Outaazza**, Développeur Full Stack, réalisé avec React. Le CV est optimisé pour l'impression au format A4 et téléchargeable en PDF.

## Fonctionnalités

- Design responsive (ordinateur, tablette, mobile)
- Mise en page A4 prête pour l'impression
- Bouton de téléchargement du CV en PDF
- Contenu géré dynamiquement à partir de données JavaScript

## Technologies utilisées

- React
- CSS3
- Bootstrap
- Git & GitHub

## Installation

```bash
git clone https://github.com/outaazzazakaria/zakaria-outaazza-cv.git
cd zakaria-outaazza-cv
npm install
npm start
```

L'application sera disponible sur `http://localhost:3000`.
